# StellarClass-ML: Deep Learning and Ensemble Methods for Automated Stellar Classification in Big Data Environments
This project delivers an end-to-end Machine Learning and Deep Learning pipeline designed to classify astronomical objects (Galaxies, Stars, and Quasars) based on spectral and photometric data from the Kaggle Playground Series (Season 6, Episode 6). Leveraging large-scale tabular datasets (144.8 MB), the system implements advanced exploratory data analysis (EDA), robust feature engineering, and high-performance classification models—specifically Random Forests (Ensemble Methods) and Artificial Neural Networks (ANNs). Additionally, the trained optimal model is packaged into a production-style, interactive web application using Streamlit to demonstrate real-time predictive capabilities on unseen space observation data.
